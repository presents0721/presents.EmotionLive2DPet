# Live2D 具身桌宠（presents.EmotionLive2DPet）

> ## ⚠ 版本区分（必读）
>
> - **本版本（5.0.0）只适配 Alife 5.0.0 及以上**（新版 WinForms + WebView2 客户端，窗口与前端通信全部改为 IAlifeApplication / alifeWindow 桥）。
> - **Alife 4.x 用户请勿安装、勿更新到 5.0.0**：4.x 没有新的窗口 API，装上会直接编译失败（CS0246 找不到 ElectronNET 或 Alife.Client 类型）。
> - **Alife 4.x 请继续使用 1.0.2**。客户端按「插件大版本号 ≤ 客户端大版本号」判断兼容，4.x 市场里不会提示升级到 5.0.0，也不会自动替换。
> - 从 1.0.2 升级到 5.0.0 只需在 5.0.0 客户端里正常更新插件；角色配置、表情校准与情绪记忆保存在 Storage/<角色>/，不受影响。

把 Cubism 3+ 的 Live2D 模型变成能被 AI 驱动的桌宠身体：情绪、表情、动作、手势、换装与窗口演出都由对话内容实时驱动。

## 一、安装与依赖

- 从插件市场安装，依赖 `Alife.Function.FunctionCaller`（AI 函数调用）与 `Alife.Function.Speech`（语音合成，用于口型同步）。
- 没有 `Speech` 也能正常显示与表演，只是不进行语音口型驱动。
- 前端第三方库（PIXI、pixi-live2d-display、Live2D Cubism Core、Soullink 表演引擎）全部随插件分发，不访问任何 CDN，断网可用。

## 二、模型从哪来（插件不附带任何模型）

出于版权考虑，插件包内**不含任何模型文件**，也不绑定某一位作者的模型。

1. 首次启动时，若默认模型目录为空，会自动下载官方示例模型包（与官方桌宠共用缓存）。
2. 也可以自己放模型：把模型文件夹（含 `*.model3.json`）放进
   `Storage/Live2DDeskPet/Models/<模型名>/`，一个模型一个子文件夹。
3. 模型可以放在任意位置：设置页「浏览模型文件夹…」添加额外目录，切换模型时会递归查找其中的所有 `*.model3.json`。
4. 找不到模型时，插件日志会给出提示与目录位置；不会因此崩溃。

## 三、窗口内操作

| 操作 | 效果 |
|---|---|
| 左键单击 | 摸头互动（按区域/部位上报给 AI） |
| 双击 | 打开输入框，直接对桌宠说话 |
| 长按 / 拖拽 | 移动窗口位置 |
| 滚轮 | 缩放模型 |
| 右键 | 菜单：打招呼、输入框、外观与表演、表情校准、**更换模型**、躲起来、设置 |
| Ctrl+Alt+H | 隐藏桌宠（托盘图标可再唤回） |

「更换模型…」会递归列出所有可用模型（含外部目录），点一下即原地热切换，无需重启插件。

## 四、表演能力

- **连续情绪**：本地文本情绪识别，支持保持与自然衰减，不需要额外模型或 API。
- **FACS 表情合成**：眼睛、眉毛、嘴形、脸颊、泪目等按面部动作单元逐帧合成；同时叠加模型自带表情，效果更明显。
- **原生资产**：自动识别模型自带的表情与动作，按名称归类并在合适的情绪下播放；识别不到时自动跳过，不报错。
- **动作层**：头部 / 身体多自由度程序化动作 + 呼吸、眨眼、视线跟随。
- **手势库**：点头、摇头、鞠躬、前倾、后仰、张望、耸肩、挥手、举双手、比心、指向；有手臂参数的模型会叠加肩部动作，没有则自动降级为头身动作。
- **窗口演出**：跳、蹦、弹、抖、横移、放大凑近、后退、转身、颤抖，模型无关。
- **换装**：自动识别兽耳、尾巴、发卡、裙摆、光环、翅膀等开关类部件，可手动固定。
- **表情校准**：按模型分别保存倍率，修改立即生效。

AI 还可以通过 `<PetGesture>`、`<PetEffect>`、`<SwitchModel>`、`<Position>`、`<Move>` 等标签直接控制桌宠。

## 五、配置与数据

- 情绪记忆、表情校准、固定的表演与服饰配置按角色保存在 `Storage/<角色>/` 下，切换角色或重启后自动恢复。
- 插件本身不收集、不上传任何数据；不包含本地绝对路径、账号或令牌信息。
- 模型文件的版权与使用许可由模型作者决定，请遵守各自的配布条款。

## 六、已知限制

- 需要 Cubism 3 或 4 的模型（`.model3.json`）；Cubism 2 模型不支持。
- 没有手臂参数的模型只能演头身层，这是模型能力限制，不是插件故障。
- 全屏独占的游戏/视频上方可能无法置顶显示，与窗口置顶策略有关。
